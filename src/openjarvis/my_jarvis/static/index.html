Step-by-Step Local Hardware Quickstart

Run this exact custom JARVIS stack on your own Mac, Linux, or Windows (WSL2) machine.

01

Install Local Ollama + Pull Starter Model (Free)

curl -fsSL https://ollama.com/install.sh | sh
ollama serve &
ollama pull qwen3:8b
02

Sync OpenJarvis + Launch My-JARVIS Command Center

uv sync --extra server --extra inference-cloud
uv run my-jarvis doctor
uv run my-jarvis serve --port 8765
03

Connect Venice AI / DeepSeek / Claude / OpenAI / Gemini (Optional)

export VENICE_API_KEY="your-venice-key"
export ANTHROPIC_API_KEY="your-claude-key"
# Or paste keys cleanly in the Brains & Keys tab!
